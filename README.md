# st-preset-organizer 预设分组管家

SillyTavern 扩展：自动检测每个「对话补全预设」适配的模型并分组，支持自定义标签、常用预设区（星标收藏）、同名版本折叠。

## 功能

- **自动分组**：综合预设名、实际模型配置（chat_completion_source + custom_model）、预设内容全文（prompts 数组/作者话）判断适配模型，自动分成
  - Claude / Gemini / DeepSeek / Claude+Gemini 皆可 / OpenAI 系 / 多模型通用 / 未识别·通用
  - 名字识别只认明确标记（Claude、Gemini、kemini=Gemini、klaude/克劳德=Claude、ds/dsvN/ds预设=DeepSeek），模糊词不下结论，拿不准的归入「未识别/通用」由你手动改
- **点击即用**：点条目直接加载该预设，当前启用预设绿色高亮
- **手动改分类**：点条目上的类别徽章，下拉选择正确分组，立即生效并记忆（检测错了随时改）
- **自定义标签**：点条目右侧标签按钮，输入回车保存，方便自己备注
- **常用预设区**：★ 星标收藏常用预设，点击即加载，支持上移/下移排序
- **版本折叠**：同名不同版本（如 `【众生相】Claude-v2.0` / `v4.4`）自动折叠成一组，默认收起，点击展开；若新版适配模型变化则不折叠
- **增量扫描**：只检测新增预设，老预设用缓存，加再多预设也不卡；检测引擎升级会自动重扫一次

## 安装

1. 下载 Release 里的 `st-preset-organizer.zip`
2. 解压到 `SillyTavern\data\default-user\extensions\st-preset-organizer\`
3. 刷新酒馆页面（F5），设置 →「对话补全预设」下拉旁边会出现一个小草莓按钮

## 使用

点小草莓打开面板：

- 顶部搜索框：按名称过滤预设
- **★ 常用预设**：点条目右侧 ★ 加入；常用区条目可点击加载、上移下移、移出
- **分组区**：每组显示类别与数量；点条目加载预设；点类别徽章改分类；点右侧 ★ 收藏、标签按钮打标签

## 更新

1. 下载新 Release 的 zip
2. 覆盖 `extensions\st-preset-organizer\` 下的文件
3. 刷新页面

## 兼容

SillyTavern 1.19+，桌面端与手机端均适用（面板自适应屏幕宽度）。
